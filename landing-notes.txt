•	Apa keuntungan memisahkan header dan footer menjadi file component tersendiri, dibandingkan menuliskannya langsung berulang-ulang di index.php?
    Jawab = salah satu keuntungan memisahkan header dan footer menjadi file component tersendiri adalah kita dapat mengedit header dan footer tanpa harus 
            mengedit setiap halaman yang memiliki header dan footer tersebut, sehingga dapat meringankan pekerjaan programmer. keuntungan keduanya adalah 
            hasil codingan di index menjadi lebih pendek dan lebih rapi. keuntungan ketiga adalah hasil codingan menjadi lebih konsisten dan dapat mengurangi
            kemungkinan kesalahan karena code tersebut tidak harus di tulis berkali kali
